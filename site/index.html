    Events widget

    Drop these two lines into any page and the next events render in place. Style it with the evt-ev- CSS classes.

    <div id="tango-events"></div>
<script src="https://tango.here.events/embed.js" data-max="8" defer></script>

    Data feeds

    The raw data behind this page, fetchable from anywhere (CORS is open):

    • events.json — JSON feed
    • events.ics — iCalendar feed

    Google and Outlook don't have feed formats of their own — they subscribe to the iCalendar feed. The Add To My Calendar button up top has one-click links for both.
